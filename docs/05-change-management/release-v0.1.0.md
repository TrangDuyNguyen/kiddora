## 🚀 1. Điểm Nhấn Phiên Bản (Release Highlights)
Phiên bản `v0.1.0` đặt nền móng kiến trúc đầu tiên cho Kiddora với đầy đủ các thành phần cốt lõi:
1. **Interactive Onboarding 3 Slides**:
   - Slide 1: Welcome & Fun Learning with 3D boy mascot.
   - Slide 2: Self-Paced Discovery & Learning categories.
   - Slide 3: Learn with Live Coaches & Video classroom value.
2. **AutoRoute 9.x Navigation Architecture**:
   - Cấu trúc router khai báo, kiểm soát Onboarding Guard kiểm tra trạng thái khởi chạy.
3. **Tactile Claymorphism UI Kit Foundation**:
   - `ClayCard`, `ClayButton`, `StarCounterBadge`, `ClaySmoothPageIndicator`.
   - Hiệu ứng rung nảy xúc giác Squish khi bấm.
